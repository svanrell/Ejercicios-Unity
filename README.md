# Entrega Ejercicios Unity

Entrega de los tres ejercicios solicitados para la práctica de Unity.

## Archivos incluidos

- `ejerciciosUnity1.unitypackage`: Paquete de Unity que contiene las escenas, scripts y materiales de los tres ejercicios.

## Ejercicios

- **Ejercicio 1.3**: Escena con plano y cubo con material azul (`Assets/Scenes/Ejercicio1.3.unity`).
- **Ejercicio 1.4**: Escena con plano y tres esferas configuradas con físicas y rebote (`Assets/Scenes/Ejercicio1.4.unity`).
- **Ejercicio 1.5**: Escena con cilindro y script `Spinner.cs` para la rotación del objeto (`Assets/Scenes/Ejercicio1.5.unity`).
