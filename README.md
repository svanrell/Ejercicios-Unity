# Entrega de Ejercicios de Unity

Repositorio correspondiente a la entrega de los 3 ejercicios prácticos iniciales solicitados en Unity.

---

## 📦 Contenido de la Entrega

El proyecto se entrega empaquetado en el archivo:
- **`ejerciciosUnity1.unitypackage`**: Paquete de Unity listo para importar con todos los recursos, escenas y scripts necesarios.

---

## 📋 Descripción de los Ejercicios

Dentro del paquete se incluyen las 3 escenas y recursos asociados:

1. **Ejercicio 1.3 (`Assets/Scenes/Ejercicio1.3.unity`)**:
   - Configuración de la escena base con plano (`suelo`), iluminación y objeto primitivo (`cubo`).
   - Aplicación de materiales personalizados (`material azul.mat`) y propiedades de visualización/físicas.

2. **Ejercicio 1.4 (`Assets/Scenes/Ejercicio1.4.unity`)**:
   - Escena con suelo y múltiples esferas (`esfera 1`, `esfera 2`, `esfera 3`).
   - Pruebas y configuración de físicas con `Rigidbody` y materiales de física (`Physic Material`), evaluando el comportamiento dinámico y rebote.

3. **Ejercicio 1.5 (`Assets/Scenes/Ejercicio1.5.unity`)**:
   - Escena con objeto (`Cylinder`) animado mediante código C#.
   - Script **`Spinner.cs`** (`Assets/Scripts/Spinner.cs`) asignado para aplicar una rotación continua en el eje deseado mediante `Time.deltaTime`.

---

## 🚀 Cómo Importar el Paquete en Unity

Para visualizar y ejecutar los ejercicios en Unity:

1. Abre un proyecto nuevo o existente en **Unity Editor**.
2. En la barra de menús superior, selecciona:  
   **Assets > Import Package > Custom Package...**
3. Selecciona el archivo **`ejerciciosUnity1.unitypackage`**.
4. En el diálogo de importación, asegúrate de marcar todos los elementos y pulsa **Import**.
5. Dirígete a la carpeta **`Assets/Scenes/`** en el panel de Proyecto y abre cualquiera de las tres escenas (`Ejercicio1.3`, `Ejercicio1.4` o `Ejercicio1.5`).
6. Pulsa **Play** para ver las simulaciones e interactividad en ejecución.
